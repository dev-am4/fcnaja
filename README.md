# BJT Policy Tracker

เว็บข้อมูลแบบ source-first สำหรับจัดโครงสร้างนโยบายของพรรคภูมิใจไทยให้ค้นหาและอ่านง่าย

## แนวคิดหลัก

- แยกคำประกาศของพรรคออกจากข้อมูลการดำเนินงาน
- ตัวเลขทุกตัวที่แสดงควรย้อนกลับไปยังแหล่งต้นฉบับ
- ใช้ timeline แทนการสรุปแบบคะแนนผ่าน/ตก
- ไม่ใช่เว็บไซต์ทางการของพรรคภูมิใจไทย
- ไม่ให้คำแนะนำทางการเมือง

## Development

```bash
npm install
npm run dev
```

เปิด http://localhost:3000

## Build

```bash
npm run build
```

## โครงข้อมูล

ข้อมูลเริ่มต้นอยู่ที่ `src/data/policies.ts` โดยแต่ละนโยบายมีคำประกาศ เป้าหมาย กลไก แหล่งอ้างอิง และ timeline
